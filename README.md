# AISecGuide

AISecGuide is an enterprise AI security guidance project focused on building a structured, auditable, and practically usable security framework for organizational AI adoption.

The repository currently includes:

- the bilingual master guidance document
- a standalone English version
- a standalone Chinese version
- supporting reference materials used during drafting and review

This project was jointly developed by `yurkingw` and AI, with human direction, review, and final decision-making applied throughout the drafting process.

## Repository Contents

- `Enterprise-AI-Security-Guidance.md`: bilingual master document
- `Enterprise-AI-Security-Guidance.en.md`: English-only version
- `Enterprise-AI-Security-Guidance.zh.md`: Chinese-only version
- `Enterprise-AI-Security-Guidance.assets/`: images referenced by the documents
- `Ref/`: source and reference materials
